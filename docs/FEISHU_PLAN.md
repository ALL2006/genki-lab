# 飞书接入规划

## 计划用途

- 使用飞书多维表格保存经过核验的研究资料、来源与处理状态。
- 使用飞书表单收集真实用户反馈。
- 使用飞书仪表盘展示用户验证结果。
- 通过导出的 CSV 文件完成首轮低风险数据交换。

## 建议阶段

1. 先确定字段、来源规范与权限范围。
2. 使用人工导出的 CSV 验证前端数据映射。
3. 完成数据合规与错误处理方案后，再评估开放平台 API。
4. 将连接逻辑放入 `src/services`，保持页面层不感知具体数据源。

## 当前状态

当前阶段尚未连接飞书 API，不需要 App ID、App Secret 或任何 API Key，也不会向飞书写入数据。
