# 数据采集合规边界

## 允许范围

- 无需登录即可访问的官网 RSS、品牌新闻中心、政府或研究机构公开文章。
- 只保存支持研究所需的标题、摘要/正文、发布时间、来源链接、获取时间和技术元数据。
- 明确标注来源、LIVE/DEMO、采集时间与质量状态，保留原文链接供人工核验。

## 禁止范围

- 不抓取小红书、抖音等强登录平台，不处理验证码，不复用个人 Cookie。
- 不绕过 robots、403、付费墙、访问频控或其他技术限制。
- 不采集账号资料、联系方式等与饮料研究无关的个人信息。
- 不把公开文章当成真实用户反馈，不把模拟 AI 结果当成真实分析结论。

## 技术控制

- 明确 User-Agent、10 秒默认超时、有限重试、指数退避、同域名默认 1 秒间隔、2 MB 正文上限。
- URL 去除跟踪参数后再去重；正文规范化后计算 SHA-256。
- 单源失败隔离并记录 HTTP/错误、失败次数、耗时；不静默失败。
- 当前 JSON 数据库仅用于单机 Demo。对外部署前应增加数据保留期、删除流程、访问控制和来源定期复核。

## 当前核验记录

2026-08-05 检查了三个启用来源：英国食品标准局与 The Coca-Cola Company 的 `robots.txt` 未禁止当前公开入口；曲靖市政府未提供可读取的 `robots.txt`（返回 404），因此只以低频读取单篇公开文章。先前返回 403 的候选来源已经从启用配置移除，没有尝试绕过。

合规判断应在比赛演示或部署前再次人工复核；网站规则可能变化。
