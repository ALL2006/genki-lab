# 内容与数据填充指南

## 1. 基本原则

- 不编造行业数据、消费者结论、报告名称、用户评论或证据来源。
- 未接入内容统一显示 `DEMO PLACEHOLDER / 待补充`。
- 区分真实研究材料、团队判断、AI 生成内容和页面占位内容。
- 所有外部资料应保存来源 URL、发布组织、发布时间和审核状态。

## 2. 研究资料

将核验后的资料按 `ResearchSource` 接口加入 `src/data/researchSources.ts`。报告文件可放入 `public/assets/reports`，竞品案例素材可放入 `public/assets/cases`。

## 3. 用户评论

用户评论必须是真实样本，并在接入前完成匿名化和使用范围检查。结构化字段应与 `UserComment` 接口一致，不得以 AI 生成评论替代用户样本。

## 4. 趋势机会

趋势机会需要能够回溯到证据来源。评分方法、样本范围和计算方式确定前，`trendScore` 与 `brandFitScore` 保持为空。

## 5. 产品概念

只有在趋势分析和团队评审后，才在 `src/data/products.ts` 添加候选概念。当前示例卡仅用于展示页面结构，不代表具体新品方向。

## 6. 营销内容

内容资产接入前应确认产品概念、品牌规范、平台要求和审核人。当前版本不创建或接入视频，不包含播放器，也不包含 HyperFrames 目录。

## 7. 用户验证

表单开放前需要绑定经过确认的产品概念，并说明数据用途。测试结束后，再将匿名化结果映射到 `ValidationResponse`，不得展示虚构统计结果。
